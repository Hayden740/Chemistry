How to balance

A balanced equation is conservation of mass written in symbols. Here is a method that works every time.

Why equations need balancing

Look at this equation for making water:

H2 + O2 → H2O

It has the right formulas, but count the oxygen atoms. There are 2 on the left and only 1 on the right. Written like this, the equation says an oxygen atom has vanished. Atoms cannot vanish, so the equation is not finished.

The balanced version is:

2H2 + O2 → 2H2O

Now there are 4 hydrogen atoms and 2 oxygen atoms on each side.

The golden rule: change only the coefficients, the big numbers in front. Never change a subscript, because that changes the substance.

The method

  1. Write the correct formulas for every reactant and product. Remember the diatomic elements, such as O2 and H2.
  2. Count the atoms of each element on both sides. A tally table helps.
  3. Fix one element at a time by adding a coefficient. Start with elements found in compounds. Leave elements that are on their own, like O2, H2 or Fe, until last, because changing them does not affect anything else.
  4. Recount everything after every change. Fixing one element can unbalance another.
  5. Check the coefficients are the lowest whole numbers possible. If every coefficient can be divided by the same number, divide them.

Common mistakes

Changing a subscript. Turning H2O into H2O2 makes the atoms add up, but it is now hydrogen peroxide, not water.

Only multiplying the first atom. 3H2O means 6 hydrogen atoms and 3 oxygen atoms. The coefficient multiplies the whole formula.

Forgetting diatomic elements. Oxygen gas is O2, not O. Hydrogen, nitrogen and chlorine are the same.

Stopping too early. Recount every element at the end, not just the one you changed last.

Leaving it unsimplified. 4H2 + 2O2 → 4H2O is balanced, but every number can be halved, so the final answer is 2H2 + O2 → 2H2O.

Shortcut for groups: if a group of atoms like SO4 or NO3 appears unchanged on both sides, you can count it as one unit instead of counting the separate atoms.
